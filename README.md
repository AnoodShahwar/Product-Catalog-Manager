# 🛍️ Product Catalog Manager
**Flutter Assignment 9**

A fully functional mobile app where you can view, add, edit, and delete products; all connected to a live REST API with real-time state management.

---

## ✨ Features
- 📦 View all your products in a clean card layout
- ➕ Add new products with validation
- ✏️ Edit existing products with pre-filled forms
- 🗑️ Delete products with a confirmation dialog
- ⏳ Loading state while fetching data
- 📭 Empty state when no products exist
- ❌ Error state when something goes wrong

---

## 🛠️ Tech Stack
- **Flutter** — UI framework
- **Provider** — state management
- **HTTP package** — REST API calls
- **crudcrud.com** — temporary live backend

---

## 🚀 Getting Started
1. Go to [crudcrud.com](https://crudcrud.com) and copy your unique endpoint URL
2. Open `lib/core/constants/api_constants.dart`
3. Replace the URL with yours
4. Run `flutter pub get`
5. Run `flutter run`
